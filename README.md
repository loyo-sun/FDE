# FDE 从入门到精通

FDE（Forward Deployed Engineer，前沿部署工程师）深入客户的真实工作场景，将业务问题转化为可运行的解决方案，并持续验证它是否带来价值。

这份中文知识库围绕“从发现问题到交付结果”组织知识，帮助你理解 FDE 的工作全貌，学习工程与 AI 应用方法，掌握客户协作、上线验收和持续改进的要点。

**[进入知识库](https://fde.loyo.work/) · [浏览交互全景](https://fde.loyo.work/docs/knowledge-map/#framework) · [选择学习路线](https://fde.loyo.work/docs/knowledge-map/#learning-routes)**

横向看能力：解决一个客户问题，往往需要业务判断、架构设计、数据处理、软件实现和跨团队协作共同参与。

纵向看阶段：同一种能力会在发现、设计、构建、上线和运行中反复使用。学习时既要掌握方法，也要知道何时使用、需要哪些前置条件、应当形成什么产出。

## 从问题到结果的六个阶段

| 阶段 | 要回答的问题 | 典型产出 |
| --- | --- | --- |
| 发现与立项 | 谁遇到了什么问题，是否值得解决？ | 问题定义、场景边界与价值假设 |
| 方案与计划 | 在现有约束下，怎样形成可执行的方案？ | 架构决策、集成契约与验证计划 |
| 构建与验证 | 怎样打通业务链路，并证明实现符合预期？ | 可运行的实现、测试与评测证据 |
| 上线与采用 | 怎样让系统进入真实环境并被用户使用？ | 上线检查、试点结果与运维移交 |
| 运行与改进 | 系统是否可靠，业务价值是否持续兑现？ | 运行指标、故障复盘与价值复核 |
| 复用与演进 | 哪些经验值得复用，哪些方案需要调整或退出？ | 可复用方案、产品反馈与演进决策 |

阶段可以往返迭代。项目的规模、目标和风险不同，需要选择的工作也不同。

## 需要掌握的七类能力

- **业务与价值**：理解客户问题，筛选场景，建立成功标准，判断投入与收益。
- **架构与集成**：识别系统边界，设计组件与接口，解释技术取舍。
- **数据与知识**：统一业务语义，接入和处理数据，维护知识的质量与更新。
- **AI 与自动化**：判断 AI 是否适用，选择模型、RAG 或 Agent，用评测控制效果与风险。
- **工程与运行**：构建可维护的系统，做好测试、部署、观测、故障诊断和成本优化。
- **安全与治理**：明确身份、权限和数据边界，验证安全控制与隐私保护。
- **协作与产品**：管理沟通、风险与变更，推动用户采用，将共性需求反馈给产品。

岗位认知、工程基础与能力评估贯穿全部阶段。可以先从[岗位与能力模型](https://fde.loyo.work/docs/role-and-competency/)了解自己的学习起点。

## 在实践中检验所学

[端到端实战项目](https://fde.loyo.work/docs/capstone-project/)以“企业售后工单助手”为教学案例，将问题访谈、方案设计、实现、评测、上线和复盘串成一条完整的练习路径。案例使用合成资料，便于学习和复现。

配合[项目交付模板](https://fde.loyo.work/docs/delivery-templates/)，逐步形成问题定义、架构决策、评测计划、上线清单、移交说明与复盘记录。用这些具体产出检查自己是否已经能够解释方案、验证结果并推动交付。
