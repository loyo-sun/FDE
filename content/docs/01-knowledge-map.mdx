[![FDE 学习路线章节图解](/diagrams/articles/knowledge-map.svg)](/diagrams/articles/knowledge-map.svg)


## 定位与使用方式

FDE 在这里指 Forward Deployed Engineer（前沿部署工程师）：深入客户工作流，识别问题，编写和集成软件，验证业务效果并反馈产品。本知识库以项目产出组织能力，不以工具数量判断水平。

10 个知识域、40 个主题均已补齐为基础指南，原有地址保持不变。每篇文章提供与章节对应的图解，另含 7 份交付模板、20 条合成评测样本和一个离线检索演示。指南提供方法、判断依据与练习，不代表经过客户现场验证的生产操作手册。

## 贯穿案例与资源

使用“企业售后工单助手”的合成案例贯穿全部知识域：一个租户、一个设备系列、授权手册检索、带引用草稿、人工审核。禁止自动发送、设备控制和自动关闭。人物、企业、数据与收益数字均为教学设定，真实项目需要重新取证。

从[端到端实战](/docs/capstone-project/)下载数据和离线演示，从[模板目录](/docs/delivery-templates/)获得交付材料。当前演示只验证关键词检索与租户/版本过滤，不提供真实模型生成或生产身份系统。

### 1. 岗位与学习基础

理解 FDE 如何在客户现场发现问题、编写软件并交付业务结果。 **完成目标：**能解释角色边界，规划自己的能力成长。

| --- | --- |
| [FDE 学习路线](/docs/knowledge-map/) | 全局大纲、学习路线与内容建设进度。 |
| [FDE 岗位与能力模型](/docs/role-and-competency/) | 理解 Forward Deployed Engineer 的责任、工程能力与协作边界。 |
| [工程基础与开发环境](/docs/engineering-foundations/) | 补齐编程、系统、网络、Git 与调试的基础。 |
| [学习路线与能力评估](/docs/training-and-certification/) | 用项目产出检验从入门到独立负责项目的成长。 |

### 2. 客户问题与业务价值

| 主题 | 解决的问题 |
| --- | --- |
| [客户访谈与问题定义](/docs/business-discovery/) | 把模糊诉求拆成用户、场景、问题与约束。 |
| [业务流程与用户研究](/docs/workflow-mapping/) | 找出真实工作流中的瓶颈、例外与人工判断。 |
| [场景筛选与范围界定](/docs/use-case-prioritization/) | 按价值、可行性、数据准备度和风险选择首个场景。 |
| [价值假设与成功指标](/docs/success-metrics/) | 把业务目标转成可测量的基线、目标和验收证据。 |

把业务问题转成数据、系统与交互方案，先验证关键假设。 **完成目标：**能解释方案取舍，并用原型验证最大风险。

| 主题 | 解决的问题 |

| [系统集成与接口契约](/docs/integration-design/) | 设计跨系统的数据流、接口、错误处理与一致性边界。 |
| [原型与技术验证](/docs/prototype-validation/) | 通过最小原型验证高风险假设，明确继续或停止的条件。 |

编写、测试和集成可维护的软件，让原型进入真实工作流。 **完成目标：**交付可运行、有测试、可追踪的软件变更。

## 分阶段完善计划

本轮完成知识体系与全部正文，后续以验证深度推进：

| 阶段 | 增量目标 | 晋级证据 |
| --- | --- | --- |
| 当前版本 | 完整方法、合成案例与学习材料 | 构建、内容检查和离线演示 |
| 项目实现 | 真实身份、持久化、队列与模型接入 | 可复现工程、契约与权限测试 |
| 生产验证 | 授权任务分布、试点与故障演练 | 质量、成本、恢复和用户采用证据 |
| 经验证复用 | 第二场景迁移、升级与真实脱敏案例 | 跨项目验证与审核记录 |

这是内容维护规划，未设置自动定时任务，未声称未来阶段已经完成。
